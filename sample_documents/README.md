# Sample Documents for DocuMind AI

This directory contains representative test documents used for evaluating the parsing and extraction pipeline in Phase 2 and LLM analysis in Phase 3.

## Included Samples:
1. `sample_resume_1.txt`: Senior Software Engineer CV with skills, experience, education, and projects.
2. `sample_research_paper.txt`: Academic paper abstract on Transformer-based Document Intelligence.
3. `sample_contract.txt`: Commercial Software Development Agreement.
